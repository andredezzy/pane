# A verified update leaves quarantine

The update's dmg leaves quarantine once it matches the release's SHA-256, so the Pane a user drags out of it opens like the one it replaces. Pane quarantines every file it writes (Chromium's `LSFileQuarantineEnabled`, which the bundle keeps), and macOS refuses a quarantined copy of an app that is not notarized (ADR 0048): "Apple could not verify “Pane” is free of malware", with Move to Trash first and Open Anyway left in System Settings, after every update. It was found running the update path against the real v0.7.0 release: the downloaded dmg carried `com.apple.quarantine`, and the app copied out of it was refused at launch.

GitHub gives each asset's SHA-256 in the release JSON (`digest`), which TLS to api.github.com vouches for (ADR 0002). The updater hashes the dmg off the main thread, in about 0.2 s for 163 MB; a dmg that differs is deleted and the update offered again, and only a matching one loses the attribute. A release without a digest downloads as before and stays quarantined, so Gatekeeper asks. Sparkle takes an update out of quarantine the same way, once its signature checks out. The Electron app's download of v0.7.0 carried no quarantine, so its users' first native Pane opens too.

Keeping the quarantine was rejected: every update would end on a dialog that suggests malware and offers the Trash first. So was removing it without the digest, which would let any file at a trusted URL skip Gatekeeper, and so was signing with a self-made certificate, which would also keep the Keychain's grant across updates (ADR 0048) but puts a private key in CI's secrets, the user's call. Revisit with a Developer ID: a notarized app opens quarantined, and Sparkle takes the updater over.

`updates` checks it against its stand-in release: a dmg that matches the digest leaves quarantine, one that differs is deleted and the update offered again, and one without a digest stays quarantined. Against the real release, a build that reported 0.6.9 found v0.7.0 3.4 s after launch, downloaded and verified its 163 MB dmg in 11.4 s, and opened it; the app copied out of it carried no quarantine, opened, and kept the old one's profile and tab. The published Electron 0.6.0, run with a throwaway home, offered v0.7.0 1.6 s after launch and downloaded and opened its dmg.
