# Architecture decisions

One record per subject, numbered in the order the subjects were first decided: the decision as the title, then why, what was rejected, and how it is checked. A later decision on a subject that has a record goes into that record, with what it changed and why. One that changes another record's subject says so at that record's top, as 0092 does. A new subject takes the next number (AGENTS.md).

- [0024](0024-devtools-in-the-app-window.md) DevTools dock beside the tab in the app's window

- [0029](0029-spellcheck-per-profile.md) Spellcheck starts with each profile
- [0031](0031-extensions-per-profile.md) Extensions run on Chrome's extension system, per profile, and their actions and popups behave as Chrome's

- [0039](0039-no-google-sign-in-workaround.md) No Google sign-in workaround

- [0042](0042-pin-lock-and-panic-wipe.md) The PIN lock and the panic wipe are the Electron app's

- [0066](0066-sidebar-reordering.md) Profiles and tabs reorder as the Electron app's did, live and as one
- [0067](0067-find-bar.md) The find bar takes Aside's design
- [0068](0068-saves-off-the-main-thread.md) Saves run off the main thread and write only what changed
- [0070](0070-one-source-per-design-concern.md) The view layer has one source per concern
- [0071](0071-voiceover-labels.md) VoiceOver names Pane's controls
- [0072](0072-favicons.md) Favicons decode once, off the main thread, into a bounded cache

- [0076](0076-web-store-says-pane.md) The Chrome Web Store's buttons say Pane

- [0084](0084-sidebar-scrolls-to-selected-tab.md) The sidebar scrolls to the selected tab
- [0085](0085-requires-macos-14.md) The app requires macOS 14, as its executable does
- [0086](0086-repo-layout.md) The repo is laid out as its peers are
- [0087](0087-app-carries-licenses.md) The app carries its licenses
- [0089](0089-app-icon-is-a-window-the-user-picks-its-sky.md) Pane's icon is a window whose sky the user picks, and the bundle carries it in Chromium's place, dated so macOS cannot show Chromium's
- [0092](0092-pane-installs-its-updates.md) Pane installs its updates itself at quit, and where it can't, says Quit and install and quits, and the update pill's bar runs to its end, drawing back for the dismiss button
- [0096](0096-extension-menu-items-show-where-chrome-shows-them.md) Extensions' own menu items and site access show where Chrome shows them, and Chrome's reload prompt after a change is declined without a dialog
- [0098](0098-extension-shortcuts-work-as-in-chrome.md) Extensions' keyboard shortcuts work as in Chrome, and are changed in a dialog of the Extensions page
- [0099](0099-wordmark-is-funnel-display-medium.md) Pane's wordmark is set in Funnel Display Medium
- [0109](0109-urls-other-apps-hand-over-open-in-panes-window.md) URLs other apps hand over open in Pane's window, and their sign-ins stay in macOS's sheet
- [0112](0112-chromiums-applescript-dictionary-stays.md) Chromium's AppleScript dictionary stays
- [0113](0113-profile-data-encrypted-under-a-key-the-pin-releases.md) Every profile's data is encrypted on disk, under a key the PIN releases
