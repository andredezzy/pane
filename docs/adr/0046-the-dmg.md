# The dmg is built as the Electron app's and laid out as Dia's

> **Window replaced by [ADR 0100](0100-installer-is-laid-out-as-harks.md)** — the window is laid out as Hark's installer; the build described here stays.

Pane's dmg is built with dmgbuild, as electron-builder built the Electron app's, and its window is laid out as Dia's installer is (the user's request). Without dmgbuild, laying out the window would mean scripting Finder, which asks for Automation permission, or writing `.DS_Store` files by hand. `engine/scripts/dist.sh` packages the app with the engine stripped (ADR 0047) and writes `app/release/Pane-<version>-arm64.dmg`, the name the update check looks for in a GitHub release (ADR 0002). It runs the same dmgbuild that electron-builder 26.8.1 downloads, dmgbuild 1.6.7 in a standalone Python, pinned by its SHA-256, and keeps the Electron dmg's UDZO at level 9 and its window's place: 400 points from the left, centered on a 1440-point screen height.

The window is Dia's in Pane's neutral colors, designed in Paper first (`08 · Installer` › 08.1 Installer window). "To install, drag **Pane** to **Applications**" sits above Pane and the Applications link, at 200 points and 420 points apart, with three chevrons between them, light to dark, on a white-to-gray wash. The volume, and so the window's title, is "Pane". `app/dmg/make-background.swift` draws the background into `app/dmg/background.tiff`, at 1x and 2x, in the system font as Finder's labels are; it replaced electron-builder's arrow (`NOTICE`). The window is 800 × 412 points, 380 of background under Finder's 32-point title bar: dmgbuild's size is the whole window, and at 380 the title bar cut off the background's bottom. The image runs 40 points taller, the wash alone, so a shorter title bar on another macOS leaves no gap. It was checked on screen, with a test dmg mounted as a user's would be and its window captured alone.

`Install Pane.command`, which the Electron dmg carried, is gone. It copied the app and cleared its quarantine, for builds without notarization, but a dmg downloaded in a browser quarantines the script too, and Gatekeeper blocks it as it blocks the app. A local build is not quarantined, and neither is the dmg the in-app update downloads. Dia's window shows only the app and Applications.

`PANE_DMG_OUT` puts a dmg anywhere, as `PANE_APP_OUT` does the app for `package.sh`, so a dmg to install from leaves the release's in `app/release` as it is. The user installs the native app by hand from such a dmg.
