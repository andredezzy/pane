# Some Chrome surfaces stay Chrome's, and some features stay off

Two Chrome surfaces stay Chrome's by decision, since neither is one the app could draw: the certificate warning page and the picture-in-picture player. The warning page is web content in the tab, not a window. The player (`VideoOverlayWindowViews`) has to host the video's compositor frame, a viz surface, which AppKit cannot show without Chromium's compositor, and AVKit's picture-in-picture plays only AVFoundation media. The app is told when the player opens and closes, and a tab in picture-in-picture does not sleep (ADR 0041). The `certificate-interstitial` and `picture-in-picture` scenarios check both. `engine/pane/browser/ui/window_host.mm` keeps Chromium's floating window for document picture-in-picture "as video picture-in-picture does" and cites `native/DECISIONS.md`, the old path of the log these ADRs replace: this ADR is the record it means, and the comment keeps the old name until the next engine change, since any edit to the engine's sources changes its key (ADR 0049).

Some of Chrome's features stay off, as they were in the Electron app. The password manager and autofill are off by prefs on each profile (`engine/pane/browser/browser_context.mm`): Pane relies on extension password managers, and `password-manager-off` signs in and sees no "Save password?" bubble. Device choosers (USB, HID, serial, Bluetooth) are declined at once, through `g_pane_device_chooser` (ADR 0021), and so is screen capture (`getDisplayMedia`). Cast is off with the `MediaRouter` feature. `device-chooser` checks that the USB, HID, and serial pickers are declined without Chrome's chooser, the page hearing `NotFoundError`; `screen-capture` checks the same for `getDisplayMedia()` and Cast, with no screen picker or Cast dialog.

Two more are off beyond the Electron app's list, because they put items in the menu bar. Glic (Gemini in Chrome) is off as a feature, beside the Media Router (`engine/pane/browser/browser_application.mm`). Chromium's testing field trials are off too (`disable_fieldtrial_testing_config = true` in `engine/args/release.gn`), which put Omnibox Everywhere's "Search with Chromium" there. The testing field trials switch on experimental features in non-official builds; Pane ships Chromium's defaults, as official builds do. The features that are off so Chrome makes no request of its own are ADR 0040's.
